# Original Italian A1: Italian to English

An original beginner course split into 13 lecture CSVs. Each card shows Italian on the front and an English meaning or usage note on the back. The lecture outline follows topic categories in the public Brainscape course listing; these cards are independently written and do not reproduce its flashcard content.

The public listing observed on 2026-11-08 was **Italian - Beginner (A1)**, with 13 decks, 422 cards, and 5,201 learners shown in Brainscape's catalog. The catalog did not identify a ranked "best" course; this was the Italian-specific beginner A1 course listed in the certified foreign-language catalog. The metadata-only listing and public deck links are in [`../brainscape-italian-public-listings.csv`](../brainscape-italian-public-listings.csv).

## In Flashlang

The course is included in Flashlang's default example collection as one class with 13 topic decks, three original everyday-conversation decks (A1–B1), and 14 original English verb-practice decks. Each verb deck has 80 cards covering the Italian meaning, past simple, past participle, -ing form, and he/she/it form. New guest libraries get the expanded course automatically. Existing guest libraries can add it with **Settings → Add examples**; signed-in libraries stay private and are not changed automatically.

To import the CSVs manually, add each lecture file to the same class and use its topic as the deck name. The filenames use topic names without sequence numbers. There are no repeated Italian prompts within the course.
